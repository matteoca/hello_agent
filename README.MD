# Local Data Agent (Ollama + LangChain + Pandas)

Un agente di Intelligenza Artificiale locale ed autonomo in grado di analizzare file dati (CSV) tramite query Python/Pandas generate al volo, senza inviare dati all'esterno.

## Requisiti

- **Python** 3.10 o superiore
- **Ollama** installato e funzionante sul PC
- Un modello locale scaricato (es. `phi3:latest` o `llama3.2:3b-instruct-q4_0`)

## Installazione
